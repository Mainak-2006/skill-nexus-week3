Mini Project 3 — Iris Flower Clustering¶

Goal: cluster the 150 Iris flowers with K-Means (K = 3), visualise the clusters, and compare them with the true species labels.

The analysis follows the script iris_flower_clustering.py:

  1. Load and inspect the data
  2. Standardise the four measurements
  3. Choose K with the elbow method and silhouette score
  4. Fit K-Means with K = 3
  5. Visualise clusters in petal space and PCA space
  6. Compare predicted clusters with true species
  7. Save/load the model with joblib and pickle

2. Standardise the features¶

K-Means minimises Euclidean distance, so every feature must be on the same scale. Petal length ranges 1.0–6.9 cm and petal width only 0.1–2.5 cm, so unscaled distances would be dominated by the larger-range features.

In [3]:
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df[FEATURES])

print("Mean after scaling:", np.round(X_scaled.mean(axis=0), 3))
print("Std after scaling: ", np.round(X_scaled.std(axis=0), 3))

3. Choose K: elbow method + silhouette¶

Inertia (within-cluster sum of squares) should drop sharply until the natural number of clusters, then flatten. The silhouette score measures how similar a flower is to its own cluster compared with the next closest one.

In [4]:
rows = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, n_init=10, random_state=RANDOM_STATE).fit(X_scaled)
    row = {"k": k, "inertia": km.inertia_, "silhouette": np.nan}
    if k >= 2:
        row["silhouette"] = silhouette_score(X_scaled, km.labels_)
    rows.append(row)
elbow = pd.DataFrame(rows)

6. Compare predicted clusters with the true species¶

In [7]:
contingency = pd.crosstab(df["species"], pd.Series(labels, name="cluster"))
display(contingency)

# Majority vote: map each arbitrary cluster id to the species it contains most.
frame = pd.DataFrame({"cluster": labels, "species": df["species"]})
mapping = (frame.groupby(["cluster", "species"]).size().reset_index(name="count")
           .sort_values("count", ascending=False).drop_duplicates("cluster")
           .set_index("cluster")["species"].to_dict())
mapped = np.array([mapping[int(c)] for c in labels])

purity = sum(contingency.max(axis=1)) / len(df)
metrics = pd.Series({
    "Silhouette": silhouette_score(X_scaled, labels),
    "Calinski-Harabasz": calinski_harabasz_score(X_scaled, labels),
    "Davies-Bouldin (lower better)": davies_bouldin_score(X_scaled, labels),
    "Adjusted Rand Index": adjusted_rand_score(df["species"], labels),
    "Adjusted Mutual Info": adjusted_mutual_info_score(df["species"], labels),
    "Normalised Mutual Info": normalized_mutual_info_score(df["species"], labels),
    "Homogeneity": homogeneity_score(df["species"], labels),
    "Completeness": completeness_score(df["species"], labels),
    "V-measure": v_measure_score(df["species"], labels),
    "Purity": purity,
    "Accuracy after mapping": (mapped == df["species"].to_numpy()).mean(),
}, name="value")
print("Cluster -> species:", mapping)
display(metrics.to_frame().round(3))

Reading the comparison

  • Setosa is recovered perfectly — all 50 flowers land in one cluster.
  • The other two clusters mix versicolor and virginica (39/11 and 14/36), which is the well-known overlap between those species.
  • Purity and mapped accuracy are 83.3%, with ARI = 0.620 and NMI = 0.659. No labels were used to fit the model.

7. Save and reload the model (joblib + pickle)¶

The bundle stores the scaler, model, feature names and cluster→species mapping. Saving the scaler with the model is essential: the loaded model must receive standardised inputs, not raw centimetres.

In [9]:
bundle = {
    "scaler": scaler,
    "model": model,
    "features": FEATURES,
    "cluster_to_species": mapping,
    "n_clusters": CHOSEN_K,
}

with tempfile.TemporaryDirectory() as tmp:
    joblib_path = Path(tmp) / "kmeans_model.joblib"
    pickle_path = Path(tmp) / "kmeans_model.pkl"
    dump(bundle, joblib_path)
    with open(pickle_path, "wb") as handle:
        pickle.dump(bundle, handle)

    from_joblib = load(joblib_path)
    with open(pickle_path, "rb") as handle:
        from_pickle = pickle.load(handle)

    pred_joblib = from_joblib["model"].predict(from_joblib["scaler"].transform(df[FEATURES]))
    pred_pickle = from_pickle["model"].predict(from_pickle["scaler"].transform(df[FEATURES]))

print("joblib predictions identical to training:", np.array_equal(pred_joblib, labels))
print("pickle predictions identical to training:", np.array_equal(pred_pickle, labels))

new_flower = pd.DataFrame([[5.0, 3.4, 1.5, 0.2]], columns=FEATURES)
new_cluster = int(from_joblib["model"].predict(
    from_joblib["scaler"].transform(new_flower))[0])
print("New flower", new_flower.iloc[0].tolist(),
      "-> cluster", new_cluster, "->", from_joblib["cluster_to_species"][new_cluster])

Conclusion¶

Question Answer
Best K by elbow 3
Best K by silhouette 2 (setosa vs. rest)
K used in the project 3 (three known species)
Setosa recovered? Yes, 50/50
Versicolor / virginica separated? Partly — they overlap
Purity / accuracy after mapping 83.3%
Adjusted Rand Index 0.620
Model persistence joblib and pickle both reproduce predictions exactly

K-Means is a good fit for this dataset because the clusters are roughly spherical and similarly sized after standardisation. Its main limitation here is the versicolor/virginica boundary: distance in the four measured dimensions cannot fully separate those two species. A supervised classifier or a density-based method (DBSCAN) would be the next step.
